# 🎭 Emotion Detection NLP

Detects emotions from text using TF-IDF + Logistic Regression.  
Trained on the [Kaggle Emotions Dataset](https://www.kaggle.com/datasets/praveengovi/emotions-dataset-for-nlp).

## Emotions
Sadness 😢 | Joy 😄 | Love ❤️ | Anger 😠 | Fear 😨 | Surprise 😲

## Setup
1. Download `train.txt` from Kaggle and place it in the project folder
2. Run `python save_model.py` to train and save the model
3. Run `streamlit run app.py`

## Tech Stack
Python · Scikit-learn · NLTK · Streamlit
